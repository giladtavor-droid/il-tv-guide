# לוח שידורים ישראלי לשבוע ומעלה

קובץ XMLTV אחד דחוס של ערוצי הטלוויזיה בישראל, 7 עד 16 ימים קדימה, שמתעדכן פעמיים ביום:

```
https://github.com/giladtavor-droid/il-tv-guide/releases/download/guide/il-week.xml.gz
```

| מקור | ערוצים | ימים קדימה |
|---|---|---|
| FreeTV | כ-72 (כאן 11, 12, 13, 14, i24, ספורט 5, ONE, מכאן, הכנסת…) | 9 עד 16 |
| סלקום TV | כ-145 (גם ערוצים בינלאומיים, סרטים וילדים) | 7 עד 16 |
| yes | ערוצים שאין בשני האחרים (ספורט 1-4, ערוצי yes…) | עד 7 |

אותו ערוץ בכמה מקורות מאוחד לערוץ אחד, מהמקור שמגיע הכי רחוק. לכל ערוץ שמות בעברית ובאנגלית, כך שאפליקציות IPTV
מתאימות אותו לפי השם.

- `build.py` בונה את הקובץ (Python 3 בלבד, בלי ספריות). `python build.py dist`
- `report.json` כמה ערוצים ותוכניות הגיעו מכל מקור בריצה האחרונה, ועד מתי.
- ריצה שיצא בה מעט מדי לא מתפרסמת, והקובץ הקודם נשאר.

הנתונים הם לוחות השידורים הציבוריים של הערוצים, מהממשקים של האתרים עצמם. אין כאן שידורים, קישורים או סיסמאות.
